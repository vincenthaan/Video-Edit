# autocut — 무음·버벅임 자동 컷 + 자막 자동 생성 (CapCut용)

영상 하나를 넣으면

1. **무음 구간**을 찾아 잘라내고
2. **버벅이는 구간**(“어…”, “음”, “그래서 그래서”, “안- 안녕하세요”)을 찾아 잘라내고
3. 잘린 영상 타이밍에 맞춘 **자막(SRT)** 을 만들어 줍니다.

결과물인 `영상_autocut.mp4` 와 `영상_autocut.srt` 를 CapCut에 가져오면 컷 편집과 자막이 끝난 상태로 시작할 수 있습니다.

```
원본.mp4 ──▶ Whisper 음성 인식(단어별 시간) ─┐
        └──▶ ffmpeg 무음 감지 ───────────────┼─▶ 컷 목록(cuts.json) ─▶ 컷 편집 영상(.mp4)
                        버벅임 규칙 분석 ─────┘                     └─▶ 자막(.srt, 편집본 기준 시간)
```

## 설치

Python 3.9 이상이 필요합니다. ffmpeg는 설치돼 있으면 그걸 쓰고, 없으면 함께 설치되는 번들 ffmpeg를 씁니다.

```bash
git clone https://github.com/vincenthaan/Video-Edit.git
cd Video-Edit
pip install -e .
```

NVIDIA GPU가 있으면 음성 인식이 훨씬 빠릅니다 (CUDA 12 + cuDNN 9 필요, faster-whisper 문서 참고).

## 사용법

```bash
autocut 내영상.mp4
```

처음 실행하면 음성 인식 모델(약 1.6GB)을 내려받습니다. 결과는 원본과 같은 폴더에 생깁니다.

| 파일 | 내용 |
|---|---|
| `내영상_autocut.mp4` | 무음·버벅임이 잘린 영상 |
| `내영상_autocut.srt` | 잘린 영상에 맞춘 자막 |
| `내영상.cuts.json` | 잘린 구간 목록 (검토·수정용) |
| `내영상.words.json` | 음성 인식 결과 캐시 (다시 돌릴 때 인식 생략) |

### CapCut으로 가져오기

1. CapCut PC 버전에서 `내영상_autocut.mp4` 를 가져와 타임라인에 올립니다.
2. **텍스트 → 자막(캡션) → 로컬 자막 가져오기**에서 `내영상_autocut.srt` 를 불러옵니다.
   (버전에 따라 메뉴 이름이 조금 다를 수 있습니다.)
3. 자막 하나에 스타일을 입히고 **모든 자막에 적용**하면 끝.

## 자주 쓰는 옵션

```bash
# 쇼츠/릴스: 자막을 짧게
autocut 영상.mp4 --max-chars 12

# 호흡을 좀 더 살리고 싶을 때 (여유를 늘리고 0.8초 이상 무음만 컷)
autocut 영상.mp4 --pad 0.2 --min-silence 0.8

# 배경 소음이 있어서 무음이 잘 안 잡힐 때
autocut 영상.mp4 --silence-db -30

# 내 말버릇도 컷 ("일단", "사실" 을 간투사로 취급)
autocut 영상.mp4 --filler 일단 --filler 사실

# "정말 정말 좋아요" 같은 의도된 반복을 살리고 싶을 때
autocut 영상.mp4 --no-repeats

# PC가 느리면 가벼운 모델 + int8
autocut 영상.mp4 --model small --compute-type int8
```

전체 옵션은 `autocut --help`.

### 컷 결과 검토하고 고치기

자동 컷이 마음에 안 드는 부분이 있으면:

```bash
autocut 영상.mp4 --dry-run          # 분석만 해서 영상.cuts.json 생성
# cuts.json 을 열어서 살리고 싶은 구간은 지우고, 자르고 싶은 구간은 추가
autocut 영상.mp4 --cuts 영상.cuts.json   # 수정한 대로 렌더링 (음성 인식 다시 안 함)
```

`cuts` 항목 예시: `{"start": 12.34, "end": 13.1, "reason": "filler"}` (원본 영상 기준 초)

## 무엇을 버벅임으로 보나

| 종류 | 예 | 규칙 |
|---|---|---|
| 간투사 | 어, 음, 으음, 어어 | 항상 컷 |
| 말버릇 | 그, 저, 뭐, 이제, 막, 약간 | **앞이나 뒤에 0.25초 이상 쉼이 있을 때만** 컷 (“그 사람”의 “그”는 유지) |
| 반복 | 그래서 그래서 / 제가 오늘 어 제가 오늘 | 1~3단어 반복은 **마지막 것만** 남김 (1초 이상 떨어진 반복은 의도된 것으로 보고 유지) |
| 말 끊김 | 안녕 안녕하세요 / 그러 그러니까 | 뒷말의 앞부분 조각이면 컷 |
| 무음 | — | -35dB 이하 0.5초 이상, 또는 단어 사이 1초 이상 빈 구간 |

간투사는 영상에 남더라도 자막에서는 항상 빠집니다.

## 한계

- **Whisper가 간투사를 안 받아적는 경우가 있습니다.** 간투사를 넣은 프롬프트로 최대한 들리는 대로 받아적게 했지만, 놓친 “어/음”은 컷되지 않습니다(쉼이 길면 무음 컷으로 잡힙니다). 정확도가 중요하면 `--model large-v3` 를 쓰세요.
- 자막 오탈자(고유명사 등)는 CapCut에서 직접 고쳐야 합니다.
- CapCut 프로젝트 파일(draft)을 직접 만들지는 않습니다. 최근 CapCut은 프로젝트 파일을 암호화해서 외부 도구로 만든 프로젝트가 버전 업데이트 때 깨지기 쉽기 때문에, 어떤 버전에서도 동작하는 **영상 + SRT** 방식을 택했습니다.
